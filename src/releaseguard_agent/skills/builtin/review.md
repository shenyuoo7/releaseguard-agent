# 代码审查技能 (SOP)

请作为资深架构与发布评审专家，对当前代码库或改动执行客观、全面的深度代码审查：

1. **架构契约与设计**: 检查模块边界、数据流向、公共 API 签名及类型严谨性；
2. **核心业务逻辑**: 重点关注边缘条件、异常捕获分支、空指针/None 处理与并发竞争；
3. **安全防护规范**: 杜绝注入风险、越界沙箱逃逸、硬编码凭据与敏感数据泄露；
4. **性能与资源治理**: 检查耗时循环、未关闭的连接或文件句柄、不必要的重复计算；
5. **代码规范与可维护性**: 遵循项目编码风格与命名约定，保持高可读性。

$ARGUMENTS

请逐步检索关键代码，并在审查完成时输出包含问题严重级别（Blocker / Critical / Major / Minor）、具体代码位置及修复方案的专业结构化报告。
