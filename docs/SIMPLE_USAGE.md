# ReleaseGuard 极简使用

日常使用只需要双击：

`ReleaseGuard.bat`

## 第一次使用

双击后选择 **5. 安装或修复运行环境**。程序会使用项目目录中的
`.venv`，不会要求 API Key，也不会安装 Docker Desktop。

这里的“不要求 API Key”只表示默认运行的是确定性离线检查。真实 LLM
智能分析必须另外安全配置 `RELEASEGUARD_LLM_API_KEY`、模型和 Provider，
并显式启用；启动器不会把确定性模式冒充成真实 LLM 调用。

## 检查项目

选择 **1. 快速检查一个项目**，粘贴项目文件夹路径即可。路径两边有
引号也没关系。检查结果会保存到 `outputs/latest_review/` 下的新时间目录。
扫描期间会显示“正在检查”，运行临时文件和 pip 缓存统一放在项目内的
`.runtime/`，不会再创建项目同级的运行目录。

## 启动网页

选择 **2. 启动网页界面**。健康检查通过后会自动打开
`http://127.0.0.1:8000/docs`。关闭新打开的服务窗口即可停止服务。

## 查看结果

报告、清单和 Trace 的完整位置会在每次操作结束时显示。修复前后对比
结果保存在 `outputs/latest_verification/`，自带演示保存在
`outputs/latest_demo/`。

## 三个常见错误

1. **找不到 `.venv`**：返回菜单选择 5。
2. **项目目录不存在**：重新粘贴正确的文件夹路径，可保留或去掉引号。
3. **端口 8000 被占用**：关闭占用端口的程序；如果已经是 ReleaseGuard，
   启动器会直接复用它。
