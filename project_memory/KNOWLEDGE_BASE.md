# Knowledge Base

## Project Knowledge Notes

This file records important concepts, reusable explanations, engineering knowledge, and review lessons for the ReleaseGuard Agent project.

## Current Notes

ReleaseGuard Agent should be developed as a staged, high-quality Agent engineering project. The first phase should establish strong foundations before implementing business logic.

Key architecture themes:

- Python backend engineering
- CLI-first local scanning
- Future FastAPI wrapper
- Checker-based release-readiness inspection
- Plugin expansion
- RAG-backed rule evidence
- Agent workflow design
- Memory and history
- Evals based on sample projects
- Observability through traces and logs
- Markdown and JSON reports

## Beginner Explanation Notes

The project memory files have different responsibilities:

- `AGENTS.md`: project-level collaboration rules for Codex.
- `PROJECT_BRIEF.md`: what the project is and what it is trying to become.
- `COLLABORATION_RULES.md`: how Codex and the user work together.
- `DECISIONS.md`: long-term technical and collaboration decisions.
- `TASKS.md`: current phase, current task, and next task.
- `CHECK_STANDARDS.md`: how work is judged as correct.
- `CHECK_HISTORY.md`: what has been checked before and what passed or failed.
- `REVIEW_LOG.md`: detailed review notes for user-submitted work.
- `KNOWLEDGE_BASE.md`: reusable explanations and project learning notes.
